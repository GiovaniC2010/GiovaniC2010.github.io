# Welcome to My Portfolio Hello! My name is GC.

## Projects
    
### 🤖 Herbie — Desktop Robot Companion 
- **Tech Stack:** Raspberry Pi 4, ESP32-S3, Touch LCD, Python, C++
- **Description:** A custom desktop companion robot powered by a Python server running on a Raspberry Pi 4 paired with an ESP32-S3 touch screen unit for dynamic UI interaction and control.

### ♟️ Lenny — Smart Chess & Interactive Bot
- **Tech Stack:** ESP32, GC9A01 Round Displays, Servo Motors, MCU-MAX Chess Engine
- **Description:** An interactive robot featuring dual round GC9A01 LCD eye displays for dynamic expressions, animated servo movement, sound feedback, and an integrated chess engine.

### 📺 ESP32 Spotify Display & Track Monitor
- **Tech Stack:** ESP32, TFT LCD, Web API, C++
- **Description:** A desktop media viewer that interfaces with Spotify APIs via an ESP32 web server to display live track metadata, playback progress, and synchronized lyrics.

### 🌐 Google Calendar ESP32-S3 Dashboard
- **Tech Stack:** ESP32-S3, Waveshare 7-inch Touch LCD, LVGL, Google Apps Script
- **Description:** A custom smart calendar dashboard that fetches schedule data through Google Apps Script and renders an interactive UI using the LVGL library.

### 🕷️ Spider-Man Web-Shooter Motion Simulator
- **Tech Stack:** ESP32-C3, MPU6050 Accelerometer/Gyroscope, Processing
- **Description:** A gesture-controlled motion system that processes real-time IMU wrist movements on an ESP32-C3 to trigger audio effects and visual animations in Processing.

### 🛠️ Interactive 3D Soldering Simulator
- **Tech Stack:** Godot Engine 4, GDScript
- **Description:** A 3D soldering simulator featuring thermal transfer physics, solder wire melting, flux smoke particle systems, component lead trimming, and fume extraction mechanics.

### ⚡ Custom Boxing Gym LED Keychains
- **Tech Stack:** KiCad 9, Bambu Lab P1S, USB-A
- **Description:** Custom-designed boxing-themed PCBs made in KiCad, combining edge-lit LEDs with 3D-printed snap-fit enclosures produced on a Bambu Lab P1S 3D printer.
