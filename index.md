## Featured Robotics Projects

### 🤖 Herbie — Desktop Robot Companion
* **Tech Stack:** Raspberry Pi 4, ESP32-S3, Touch LCD, Python, C++
* **Description:** A custom desktop companion robot powered by a Python server running on a Raspberry Pi 4 paired with an ESP32-S3 touch screen unit for dynamic UI interaction and remote control.

### ♟️ Lenny — Smart Chess & Interactive Bot
* **Tech Stack:** ESP32, GC9A01 Round Displays, Servo Motors, MCU-MAX Chess Engine
* **Description:** An interactive desktop robot featuring dual round GC9A01 LCD eye displays for dynamic expressions, animated servo motor movement, sound feedback, and an integrated lightweight chess engine.

## Embedded Systems & Sensors

### 📺 ESP32 Spotify Display & Track Monitor
* **Tech Stack:** ESP32, TFT LCD, Web API, C++
* **Description:** Built a custom desktop media viewer that interfaces with Spotify APIs via an ESP32 web server to display live track metadata, playback progress, and synchronized lyrics.

### 🌐 Google Calendar ESP32-S3 Dashboard
* **Tech Stack:** ESP32-S3, Waveshare 7-inch Touch LCD, LVGL, Google Apps Script
* **Description:** Developed a custom desktop smart calendar dashboard that fetches schedule data through Google Apps Script and renders an interactive UI using the LVGL library.

### 🕷️ Spider-Man Web-Shooter Motion Simulator
* **Tech Stack:** ESP32-C3, MPU6050 Accelerometer/Gyroscope, Processing, Piezo
* **Description:** Motion-controlled gesture system that processes real-time IMU wrist movements on an ESP32-C3 to trigger audio effects and visual web-slinging animations in a Processing application.

## Game Dev & Simulations

### 🛠️ Interactive 3D Soldering Simulator
* **Tech Stack:** Godot Engine 4, GDScript
* **Description:** Created a realistic 3D soldering training simulator featuring real-time thermal transfer physics, solder wire melting, flux smoke particle systems, component trimming, and fume extractor mechanics.

### 🏰 C++ & Raylib Dungeon Crawler
* **Tech Stack:** C++, Raylib
* **Description:** Built a lightweight 2D/3D dungeon crawler game engine from scratch using C++ and the Raylib graphics library to manage movement, collision detection, and rendering.
